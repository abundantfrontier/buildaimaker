# Extra documentation

**Start with the [main README](../README.md).** That page is written for humans who want to run the app.

This folder is extra detail. Some files are **plans from July 2026**. Headers on those files say what actually ships in the alpha.

**What the alpha does:** make a character, teach them from stories on your Mac, chat (Apple’s on-device model or a local one you installed), and hear a built-in creature voice. Copying a real voice, shareable “persona zip” files, and mic Talk are **not** in the sidebar.
